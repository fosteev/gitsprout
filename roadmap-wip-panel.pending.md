## Проверить руками

Один проход F5 (Extension Development Host) по репо с изменениями, ~10 минут:

1. Открыть граф, выбрать строку WIP вверху: справа панель 380 px (Unstaged/Staged, внизу Amend, summary со счётчиком 72, description, кнопка). Строка WIP в графе — `// WIP` и «N files»; набрать summary — строка графа показывает его.
2. Сохранить файл в редакторе — он появляется в Unstaged за ~1 с, а набранный в этот момент текст и каретка в summary не сбиваются (watcher рабочего дерева, этап 2).
3. Stage / Unstage файла кнопками строки (видны при hover и по Tab), Stage All / Unstage All. Быстрый двойной клик по Stage стейджит один файл, а не соседний.
4. Discard файла (модалка «Discard changes in 'x'?»; для untracked — «The file will be deleted»), Discard All (модалка с числом файлов). На конфликтном (`U`) файле Discard нет.
5. Path/Tree, Collapse All/Expand All, свернуть секцию и папку; один и тот же файл частично застейджен — виден в обеих секциях.
6. Пустой Staged: кнопка «Stage Changes to Commit» стейджит всё. Пустой summary + Commit — красная ошибка «Enter a commit summary.», ничего не уходит.
7. Коммит с pre-commit хуком в реальном репо (Pilot7, если там есть хук): отказ хука — текст черновика остался, «Commit failed: …» с Show Command Output; успех — черновик очищен, вспышка «Committed abc1234» в статус-баре. Двойной клик / зажатый ⌘↵ — один коммит.
8. Commit and Push из меню ▾ (Escape и клик снаружи закрывают меню). С медленным post-commit хуком (`sleep 10`) нажать Cancel в «Committing…» — коммит есть, черновик очищен, push не стартует.
9. Amend: на пустом черновике подставляется сообщение HEAD; на запушенном HEAD — заметка «HEAD is already pushed…», ▾ пропадает; снять галку — неизменённый префилл очищается. На ветке без коммитов (`git checkout --orphan x`) галка недоступна и снята.
10. Черновик (summary/description/Amend), Path/Tree и свёрнутые папки переживают переключение вкладок, уход на коммит и обратно на WIP, перезагрузку окна (Developer: Reload Window).
11. При открытой вкладке графа запустить `while true; do date >> tmp.log; sleep 0.1; done` и сделать коммит из терминала — граф обновляется за ~2 с, окно не тормозит; на большом репо (Pilot7) сравнить отзывчивость с открытой и закрытой вкладкой графа.
12. Светлая и тёмная темы: кнопки строк, меню ▾ (тень, подсветка), счётчик краснеет за 72, фокус-рамки. Сузить окно < 900 px: панель уходит под граф, прокручивается, кнопка Commit не обрезана.
